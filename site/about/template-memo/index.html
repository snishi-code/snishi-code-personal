テンプレメモ

決まった型で何度も書くメモのためのツールです。あらかじめ作ったテンプレートに沿って、 対象ごとの記録を組み立てます。よく使う文はワンタップで入れられ、まとまった文章として 書き出せます。

基本の使い方

対象を並べて、テンプレートに沿って書く
  • 記録したい対象を追加します。グループごとに分けて管理し、タグで絞り込めます。
  • 対象ごとに、テンプレートの項目を埋めます。よく使う文は「正常文」としてワンタップで入ります。
  • 入力内容は場所ごとにその場で合成され、QRコードで取り出せます。
  • ホームの左端から状態を切り替えられ、進み具合が一覧で分かります（未 / 途中 / 済 / 転記済 / 特記）。

使いこなすと便利なこと

型を育てるほど入力が短くなります
  • テンプレートはアプリ内で編集でき、場所・フォーマット・項目の構成を自分で組めます。
  • フォーマットは「展開」「呼び出し」「メニュー」の3つの配置から選べます。
  • 項目は数値・日付向けの入力、正常文、複数候補からの選択を組み合わせられます。
  • 空欄のある枝は区切りごと消えるので、埋めた分だけが自然な文章になります。
  • 1回分の入力をまとめてクリアでき、直前の状態に1段階戻せます。
  • テンプレートはQRコードで別の端末へ渡せます（記録した内容は含みません）。
  • JSON の書き出し・読み込みでバックアップや端末移行ができます。

データとセキュリティ

入力データは端末内に保存されます
  • このアプリは外部サーバーへデータを送信しません。
  • QRコードで渡せるのはテンプレートの定義だけで、記録した内容は含みません。
  • JSON export/import は、バックアップと端末間移行のための機能です。
  • 端末の紛失、故障、ブラウザデータ削除に備えて、定期的にバックアップしてください。
